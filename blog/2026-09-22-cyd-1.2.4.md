**We're pleased to announce Cyd 1.1.4 is released.** There's a lot of new code in this release that is still hidden behind feature flags, so you won't be able to use it quite yet.

Here are some highlights for what's new:

- Major fixes: X completely changed their platform, which has caused Cyd to remain in a broken state for month. We have figured out all of the changes and updated Cyd to work with X again. Note that DM support is removed, since X has migrated to X Chat, and we have not started supporting X Chat yet.
- New feature: Credentials are now stored in your operating system's keychain
- New feature: Tombstone mode helps you automatically update your X profile, and lock your account, when you're quitting for good
- Behind a feature flag: Lots of work towards Facebook support
- Behind a feature flag: Lots of work towards Bluesky support
- Transparency: Warn about the positibility of account suspension by X

See the [release on GitHub](https://github.com/lockdown-systems/cyd/releases/tag/v1.2.4).
